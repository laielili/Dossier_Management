Listen Folder

Set the Listen Folder (base directory where your project folders live). New project folders dropped into it can be processed with one click — or automatically when Auto-Watch is on. The path is saved locally and reused next time.

Auto-Watch Listen Folder OFF
When ON, the app monitors the Listen Folder. Any new project folder dropped in is picked up (after its upload finishes) and the full pipeline runs automatically. Denoised files land in Dossier_condensed/<project>/.
excluded from watch: /Dossier_condensed

Run Pipeline

One click runs the whole pipeline for every project folder found in the Listen Folder: scan → classify → ingest → condense. Each source dossier is denoised (noise pages dropped) and saved as a cleaned per-document PDF under <Listen Folder>/Dossier_condensed/<project>/ (one subfolder per project, organized by CLINS/FE/CE). Noise filtering is always on — tune it in the Config button above.
