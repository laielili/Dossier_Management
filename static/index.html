Listen Folder

Set the Listen Folder (base directory where your project folders live). New project folders dropped into it can be processed with one click — or automatically when Auto-Watch is on. The path is saved locally and reused next time.

Auto-Watch Listen Folder OFF
When ON, the app monitors the Listen Folder. Any new project folder dropped in is picked up (after its upload finishes) and the full pipeline runs automatically. Results go to Dossier_condensed/.
excluded from watch: /Dossier_condensed

Run Pipeline

One click runs the whole pipeline for every project folder found in the Listen Folder: scan → classify → ingest → package. Finished PDFs are saved to <Listen Folder>/Dossier_condensed/.

Pages whose keyword + structure score both fall below the Deletion Floor are deleted. Raise it to drop more low-information pages; lower it to keep more. Default 3.0. Click Save to apply — it then affects every run, including Run Full Pipeline.
