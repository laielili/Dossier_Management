Banner / section-title / side-tab font size (cosmetic, does not change page count).

1.0×

Table / card text size. Larger → content grows → more pages; smaller → fewer pages.

1.0×

Scales every region padding + inter-component gap. Larger → less fits per page → more pages.

0 (auto)

0 = no cap (add pages, full fidelity). A positive value is a hard cap: the engine compresses the overflow column — font-size, vertical spacing, inter-card gap and intra-card horizontal whitespace — until the deck fits. The density factor is near-unbounded (floor 0.15), so readability is sacrificed when needed to honor the cap.
